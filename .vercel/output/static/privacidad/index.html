Política de privacidad

Esta web existe para hacer sorteos de amigo invisible. Te contamos con claridad qué ocurre con tus datos.

Qué datos usamos

El nombre, el correo y, si se indican, las ideas de regalo de cada participante, además del nombre del sorteo, el presupuesto y la fecha.

Para qué

Únicamente para realizar el sorteo, enviar a cada participante su correo y permitirle consultar y editar su lista de deseos. No los usamos para publicidad ni los cedemos a terceros.

Qué guardamos y cuánto tiempo

Los correos electrónicos no se guardan nunca: se usan para enviar los emails y se descartan.

Para que cada participante pueda ver la lista de deseos de su amigo invisible y editar la suya, guardamos de forma temporal el nombre de cada participante, su lista de deseos, el nombre de la persona a quien regala, el nombre del sorteo, el presupuesto y la fecha. Se asocian a un enlace privado y aleatorio que solo recibe cada participante.

Estos datos se borran automáticamente 7 días después de la fecha del intercambio (o a los 45 días si no indicaste fecha).

Proveedores

Para enviar los correos usamos un proveedor de email transaccional, para guardar temporalmente las listas un servicio de base de datos en la nube (Upstash Redis) y, para evitar abusos, Google reCAPTCHA.

Importante

Introduce solo los datos de personas que saben que participan en el sorteo.
